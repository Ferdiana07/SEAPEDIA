# Audit katalog, aplikasi, dan dependensi — 31 Oktober 2026

## Verdict

Implementasi memiliki alur marketplace yang koheren dan tetap mempertahankan identitas SEAPEDIA. Perubahan ini mengganti seluruh foto fixture dengan foto internet yang ditinjau, menambah katalog, serta memperbaiki temuan keamanan, data, dan UI yang dapat direproduksi. Ini audit source dan aplikasi lokal, bukan sertifikasi keamanan atau WCAG.

## Ruang lingkup dan metode

- Source Laravel: route, autentikasi, middleware peran, katalog, toko, validasi produk, review, cart, wallet, order, service checkout/refund, dan seeder.
- Source React: katalog, detail produk/toko, pencarian navbar/footer, pagination, dialog, profil, saldo, promosi, dan dashboard empat peran.
- PHPUnit pada SQLite in-memory; migrasi dan full seed pada SQLite khusus E2E. Database kerja lokal menggunakan MySQL dan hanya menerima sinkronisasi ProductSeeder.
- Chrome headless melalui Playwright: navigasi publik dan seluruh peran, foto lokal, filter, dialog, dan pemeriksaan axe WCAG 2 A/AA serta 2.1 AA.
- Layout diperiksa pada 360, 390, 768, dan 1440 px. Touch banner diuji dengan TouchEvent sintetis di Chromium; belum diuji di ponsel fisik.
- Audit Composer, npm frontend (production dan development), npm scaffolding backend, lint, build, integritas file foto, dan detector Impeccable.

## Katalog dan foto

- **40 produk**, bertambah **24** dari katalog awal 16; delapan kategori masing-masing lima produk, tersebar pada tiga toko demo.
- Seluruh 40 foto diunduh dari **Wikimedia Commons**, diperiksa melalui contact sheet, lalu disimpan lokal di frontend dan backend. Tidak ada foto yang digenerate pada pekerjaan ini.
- Manifest `seapedia-frontend/public/images/products/sources.json` menyimpan halaman sumber, URL unduhan, pembuat, lisensi, perubahan format, ukuran, tanggal akses, dan SHA-256.
- Kredit publik tersedia di `/photo-credits.html` dan ditautkan dari footer. Lisensi masing-masing foto tetap berlaku, termasuk ShareAlike.
- Foto menjadi WebP 800 × 800 dengan ruang tepi agar objek tidak terpotong. Total **3.007.720 byte per aplikasi**, rata-rata sekitar 75 kB/foto. Listing memakai lazy loading.
- Nama fixture yang sebelumnya tidak cocok dengan foto diganti, antara lain pelampung pancing, refraktometer, lampu akuarium, dan potongan tuna. Harga, kemasan, stok, serta penjual tetap merupakan data simulasi.
- `ProductSeeder` sekarang membaca `database/data/demo-products.json`, mencari toko melalui akun pemilik demo, dan dapat dijalankan ulang. ID produk, stok, harga yang telah berubah, status nonaktif, upload seller, cart, serta order dipertahankan. Pengujian ulang pada database kerja menghasilkan **0 produk baru** setelah penambahan pertama.
- Koreksi pajak dan ledger berlaku pada **full seed baru**. Riwayat pesanan serta ledger database kerja tidak ditulis ulang.

## Temuan tersisa dan batas audit

1. **[P2] Advisory development minimatch.** Enam entri npm berasal dari satu akar ReDoS (`GHSA-g3hv-75wg-m249`) pada minimatch dan dependency ESLint. Jalur ini tidak termasuk bundle production. Versi yang memenuhi perbaikan advisory melewati major yang digunakan toolchain; tidak dilakukan override paksa yang belum terbukti kompatibel. Tindak lanjut: perbarui ESLint/config-array ketika dukungan tersedia, lalu lint dan audit ulang.
2. **[P2] Production dan concurrency belum diuji pada PostgreSQL.** Test transaksi/otorisasi/lifecycle lokal lulus, tetapi SQLite tidak membuktikan penguncian baris PostgreSQL atau beban paralel nyata. Jalankan test integrasi PostgreSQL dan smoke test hosting sebelum penggunaan produksi.
3. **[P2] Pengaturan motion global lama.** `index.css` masih memiliki fallback global 0.01ms. Banner sekarang memiliki perilaku reduced-motion eksplisit, tetapi halaman lain belum diberi alternatif motion per komponen. Rekomendasi: `$impeccable animate` untuk mengganti fallback secara bertahap.
4. **[P3] Konsistensi style dan target sentuh halaman lama.** Tidak semua kontrol kecil di seluruh aplikasi telah dinaikkan ke 44 px; beberapa dashboard masih memakai token lokal. Lanjutkan `$impeccable adapt`, kemudian `$impeccable polish` bila melakukan pass UI berikutnya.

Positive findings: otorisasi dan ownership tetap di backend; checkout/refund memakai transaksi; idempotency, status history, upload validation, dan lazy route splitting sudah tersedia. Pemeriksaan ini tidak menguji payment gateway nyata, email delivery, bucket production, TLS hosting, penetration test eksternal, atau perangkat fisik.

```powershell
# Root proyek: tidak memerlukan internet
python scripts/import-catalog-photos.py --check

cd seapedia-backend
php artisan test --compact
vendor\bin\pint --test
composer audit --locked
npm ci
npm run build
npm audit

cd ../seapedia-frontend
npm ci
npm run lint
npm run build
npm run test:e2e
npm audit --omit=dev
npm audit
```

Laporan axe dan screenshot dibuat ulang di `tmp/qa/audit-20261031/`. Database E2E berada di `tmp/e2e/`, sengaja di luar version control. Untuk memperbarui **hanya katalog demo** pada database kerja yang sudah ada, jalankan `php artisan db:seed --class=ProductSeeder` dari backend; jangan menjalankan full seeder atau migrate:fresh pada data kerja.
